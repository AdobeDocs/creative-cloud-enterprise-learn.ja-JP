# 数時間ではなく数分でシームレスなベクターパターンを作成

繰り返しの端を手作業で確認することなく、Illustratorでシームレスなブランドパターンを構築する方法について説明します。 「パターンを生成」を使って開始点を作成する方法、独自のロゴアイコンをタイルにドロップする方法、パッケージ、トート、イベントの背景に合わせて繰り返しを拡大・縮小する方法をご覧ください。 また、Generative Recolorが、完全に編集可能な1つのデザインから3つのカラーウェイを構築する方法も説明します。
